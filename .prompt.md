# Lovable Project Prompt - Public Access Mode

## Objetivo
Configurar a aplicação para funcionar como o Google: totalmente acessível sem autenticação obrigatória. Usuários podem usar todas as funcionalidades sem criar conta.

## Requisitos Funcionais

### 1. Acesso Público Padrão
- A aplicação deve carregar e funcionar **sem login** na primeira visita
- Autenticação deve ser **opcional**, não obrigatória
- Usuários podem usar a aplicação como "Guest" por padrão

### 2. Modo Guest
- Implementar modo guest completo:
  - Acesso a chat e geração de imagens
  - Créditos/energia limitados por sessão
  - Limite de requisições (ex: 3 chats/dia, 2 imagens/dia sem conta)
  - Dados da sessão armazenados localmente (sessionStorage/localStorage)
- Mostrar banner: "Crie uma conta para mais recursos"

### 3. Autenticação Opcional
- Oferecer login/registro quando o usuário quiser:
  - Opção em menu/settings discretamente
  - Após atingir limite de guest
- Preservar histórico se o guest fizer login depois

### 4. Layout e UX
- Remover obrigatoriedade de login da tela inicial
- Mostrar a aplicação em modo preview/demo imediatamente
- Oferecer autenticação como upgrade opcional

### 5. Dados e Persistência
- Guest: dados salvos apenas em localStorage (sessão)
- Autenticado: dados salvos no Supabase (persistente)
- Migrar dados guest → autenticado ao fazer login

## Mudanças Técnicas

### AuthGate ([src/components/hub/AuthGate.tsx](src/components/hub/AuthGate.tsx))
- Permitir renderização do conteúdo sem autenticação
- Mostrar UI de guest por padrão, opção de login no canto
- Remover redirecionamento forçado para login

### HubProvider ([src/lib/hub-store.tsx](src/lib/hub-store.tsx))
- Implementar estado guest no contexto
- Gerenciar limites de créditos para guest
- Sincronizar dados guest ↔ autenticado

### API Routes ([src/routes/api/chat.ts](src/routes/api/chat.ts), [src/routes/api/images.ts](src/routes/api/images.ts))
- Aceitar requisições de guest (sem session)
- Validar limites de guest (IP + deviceId)
- Retornar créditos disponíveis no response

### UI Components
- Adicionar indicador visual "Usando como convidado"
- Botão "Entrar" discreto no header
- Modal de upgrade quando limite atingido

3. ✅ Limites de guest implementados
4. ✅ Oferecimento de login após limite
